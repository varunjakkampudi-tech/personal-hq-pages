# Personal HQ life system

This folder brings past notes, current tasks and future plans into one dashboard. It is committed to the public `varunjakkampudi-tech/personal-hq` repository, so every file and its Git history can be read by anyone. It contains task metadata and planning material only. Never add your resume, profile contents, customer records, contact details, identity documents, credentials, health records or banking/tax identifiers.

## Open and use

Open `index.html` in Chrome or use the GitHub Pages site. The dashboard supports task search and filters, status changes, add/edit, project progress, timeline, daily routine check-ins, backup, restore and a current task export. Changes are stored in the current browser's local storage; they do not sync automatically. Use **Backup** before changing device. Use **Export tasks** to make a fresh snapshot for the 9 AM review. The desktop watcher publishes a sanitized task feed; Pages users can select **Load latest tasks** to replace their local task list after backing up. On Pages, **Refresh task evidence** merges desktop-supported sources, next actions and notes for seeded tasks while preserving browser statuses and locally edited fields; the unresolved dashboard reconciliation banner remains until a fresh export is synced.

## Data quality

`tasks.json` is a safe starter snapshot derived from the Personal HQ task list on 19 November 2026. Its source registry was marked unreconciled. Therefore its recorded statuses and calculated percentages are not independently confirmed current. Use the dashboard export after reconciling statuses against current evidence. Completed work remains in the list; unfinished items carry forward.
