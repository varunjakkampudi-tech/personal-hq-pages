# Personal HQ life system

This folder brings past notes, current tasks and future plans into one dashboard. It is committed to the public `varunjakkampudi-tech/personal-hq` repository, so every file and its Git history can be read by anyone. It contains task metadata and planning material only. Never add your resume, profile contents, customer records, contact details, identity documents, credentials, health records or banking/tax identifiers.

## Open and use

Open `index.html` in Chrome or use the GitHub Pages site. The dashboard supports task search and filters, status changes, add/edit, project progress, timeline, daily routine check-ins, backup, restore and a current task export. Changes are stored in the current browser's local storage; they do not sync automatically. Use **Backup** before changing device. Use **Export tasks** to make a fresh snapshot for the 9 AM review. The desktop watcher publishes a sanitized task feed; Pages users can select **Load latest tasks** to replace their local task list after backing up. On Pages, **Refresh task evidence** updates supported fields for seeded tasks, adds previously unseen desktop tasks using public fields only, and preserves browser statuses, private notes and local-only tasks. When a task has private notes, confirm explicitly before clearing them. Exporting a fresh dashboard snapshot preserves existing private registry notes for blank imported note fields unless you confirm clearing them. Notes added to a newly imported task are appended to any existing private note during sync. Public task snapshots allowlist task metadata; public history contains milestone summaries only and omits free-text supporting evidence. The complete task registry and supporting records stay in ignored local private storage.

## Data quality

`tasks.json` is generated from a reconciled current-user export. Statuses represent recorded dashboard values and still require evidence review before completion claims. Completed work remains in the list; unfinished items carry forward.
