## Resume and interview acceptance gates

Before approving a resume or changing any profile, use the private career workbook and verify:

- Chronology: employer, role/title changes, start/end dates, employment type and any overlapping periods, using non-confidential records.
- Ownership: for each frontend, backend, database, test and infrastructure claim, record whether Varun designed, implemented, debugged, reviewed or only observed the work. Do not turn project code or an account-authored PR into a sole-authorship claim without confirming the actual contribution.
- Projects: map every proposed project bullet to a repository/PR, exact feature slice, personally owned contribution, validation evidence and allowed disclosure. Keep local, CI, branch-merged and production evidence distinct.
- Results and skills: keep measurable claims only when baseline, method, period, attribution and disclosure are defensible; separate hands-on proficiency from technologies merely present in a project.
- Resume review: classify each statement as verified, needs clarification or unsupported. Unsupported claims are removed or rewritten as accurate scope before approval.

Interview preparation can start in parallel with chronology and evidence verification: assess current skills, practice fundamentals and record mock-interview gaps without waiting for a final resume. Prepare two project explanations only as personal contributions are confirmed; cover architecture, a design trade-off, a failure/edge case, validation and ownership. Build practice around the confirmed target and actual skill gaps; do not assume a particular seniority or stack beyond verified experience.

Keep two separate approval gates: (1) Varun accepts the exact private master-resume copy; (2) Varun separately approves the exact profile text, resume version, visibility and action before any upload, public profile change, application or outreach. Approval of one does not imply approval of the other.


## Additional portal privacy gates

**Foundit:** Its current privacy notice says it may collect publicly available personal information from unregistered users and third-party sources, including LinkedIn and Facebook, to make profiles accessible to potential employers. Registration may not be the first point at which public profile data is processed. Before using Foundit, check whether a profile already exists, clarify current opt-out, correction and deletion routes with Foundit, and proceed only if this exposure is acceptable. Recheck the live notice and controls at setup.

**Wellfound:** It says its Public Profile remains viewable even when the Jobs Profile is closed. Jobs Profile recruiter visibility depends on job-search settings or applications; current-employer exclusion depends on marking the current role accurately. The help page was last updated 23 February 2023, so recheck live settings at setup. [Foundit privacy notice](https://www.foundit.in/info/privacy); [Wellfound profile visibility](https://help.wellfound.com/article/829-how-do-profiles-work-what-is-the-difference-between-a-job-profile-and-public-profile).
