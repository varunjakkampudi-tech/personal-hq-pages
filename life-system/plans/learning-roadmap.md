# Learning roadmap

## Purpose and rules

A restart-from-basics, evidence-led path for the current full-stack engineering direction. There are no assumed weekly hours or finish dates. Choose a sustainable slot after checking the current calendar. Older plans for two hours daily, one-month sprints, and scheduled AWS/DevOps sessions are historical and are not active commitments. Keep all learning tasks until explicitly completed or changed; do not reset them in the daily review. A course request, tutorial discussion, mock interview, or published guide is not evidence of completing a course or certification.

Use one small build or written checkpoint per topic. Record dates, links, labs, and artifacts privately. Never put credential IDs or account details in this public plan. Verify course availability, versions, prices, and certification requirements before enrollment.

## Sequence

1. **Starting point and fundamentals:** review JavaScript, TypeScript, browser basics, Git/GitHub, command line, and practical DSA. Historical ChatGPT messages suggest a JavaScript revision checkpoint before moving to React, but this is not independently verified; start with a short diagnostic.
2. **Frontend:** React components, hooks, state, routing, forms, API integration, testing, performance, and accessible responsive UI; then Next.js fundamentals. Build a deployed, documented interface. Do not split Next.js App Router into a duplicate track.
3. **SEO and accessibility:** semantic HTML, metadata, canonical/indexing basics, structured data, performance/Core Web Vitals, WCAG practices, keyboard and screen-reader checks. Apply to a real portfolio project.
4. **Backend and APIs:** Node.js, Express, REST, authentication/session security, validation, error handling, testing, and Python/FastAPI as a second backend option; explore GraphQL after REST fundamentals.
5. **Data:** relational modeling and SQL with PostgreSQL/MySQL; MongoDB and DynamoDB/NoSQL tradeoffs; migrations, indexes, transactions, backups, and safe data access.
6. **System design:** requirements, API and data design, caching, queues, availability, security, and cost. Use small diagrams and explain tradeoffs.
7. **Microfrontends and AEM:** learn integration patterns after solid React fundamentals; then AEM components, HTL, client libraries, and Sling Models where useful to target roles.
8. **Cloud foundations, AWS:** IAM concepts, networking, compute, storage, databases, serverless, queues/events, deployment, monitoring, cost, and security. Build a small end-to-end app. AWS Developer Associate and prior AWS DevOps plans are study interests, not completed certifications.
9. **Cloud foundations, GCP:** projects/IAM, networking, compute, storage, managed data, deployment, monitoring, security, and cost. This track was newly requested and has no historical progress evidence. Build the same small app or a comparable workload and compare services.
10. **DevOps foundations:** Linux, networking, shell, Docker, Kubernetes basics, CI/CD with GitHub Actions, infrastructure-as-code concepts, secrets handling, rollback, and release discipline. Historical messages report a four-month AWS/DevOps training starting May 4, 2026 and Linux practice; current status is unknown, so first reconcile before repeating paid training.
11. **Monitoring and operations:** metrics, logs, traces, service objectives, alert quality, dashboards, incident response, and cost. Datadog was previously selected for exploration; confirm whether still relevant before paying. Instrument the capstone and exercise one alert and one failure scenario.
12. **Python, data and AI:** Python, NumPy, pandas, ML concepts, and GenAI fundamentals as supporting skills. Keep this behind core full-stack foundations unless a specific project needs it.
13. **Agentic AI:** start with Hugging Face and DeepLearning.AI foundations, then LangChain, plus the requested OpenAI Academy agentic AI course. Compare tool use, retrieval, state, evaluation, safety, and cost. Historical selection of this sequence is not course completion evidence.
14. **Portfolio and job readiness:** build one full-stack product with responsive frontend, secure API, database, deployment, SEO/accessibility evidence, observability, and a concise architecture note. Add targeted smaller labs for AWS/GCP and agentic AI. Practice DSA, system design, and explaining prior work. Keep resume/profile edits in private review copies until approved.
15. **Credential research queue:** verify current requirements and value before choosing among AWS Developer/DevOps, GCP, IBM/Simplilearn data science, NVIDIA AI, Microsoft DevOps Expert, GenAI, Linux+, and Datadog. These are historical interests only; none is recorded as completed here except the owner-reported Copilot credential noted privately.

## Working checkpoints and progress tracking

Keep every track in the task registry until its evidence-based completion is recorded. A daily email summarizes the work; it never resets or replaces tasks. At each weekly review, choose one next build/checkpoint that fits the actual week, update its task, and carry every unfinished item forward. Do not treat every topic as a parallel course: complete the core full-stack capstone first, then add AWS/GCP, monitoring and agentic-AI labs that support it. Keep the small study log, course links, artifacts and credential evidence private.

For each topic, record one of: **not started**, **started**, **paused**, **completed with artifact**, **credential reported but unverified**, or **decided not to pursue**. Preserve the historical note if a track is paused or dropped, and record the owner's decision/date before changing its active status. The 2026-11-21 review of the current ChatGPT conversation index and selected threads is a bounded first pass, not proof that every older conversation has been read. Continue reconciling project histories through the Life Admin task.
