# Personal HQ · GitHub Pages edition

A public, static Personal HQ template for GitHub Pages. It contains generic categories and no personal tasks or profile information.

## Privacy and storage

GitHub Pages sites are public. Tasks and check-ins entered after loading are stored in that visitor’s browser local storage; they are not uploaded, shared, or synchronized across devices. Use the in-app Backup and Restore controls to move data manually. Do not enter secrets, credentials, sensitive personal information, or private work details into this public site.

This is a client-only dashboard. It has no account system, server-side database, authentication, or cross-device sync. A backup file you restore is read in your browser and saved in local storage; it is not sent to the Pages host by the application.

## Publish

Create a public GitHub repository containing only `index.html`, `life-log.html`, this `README.md`, and `.nojekyll`. Then set **Settings → Pages → Deploy from a branch**, select `main` and `/(root)`. The public website URL will appear in the Pages settings after deployment completes. Do not push the private desktop Personal HQ folder into this repository.

## Local use

Open `index.html` directly in a browser. Browser storage is local to that browser and device.
