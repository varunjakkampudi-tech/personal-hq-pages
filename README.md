# Personal HQ

The Pages site redirects to [`life-system/`](life-system/), a responsive life dashboard with task tracking, dated history, project plans, routine check-ins, and backup/restore.

## Public data and sync

This repository and website are public. The task list, milestone summaries, and planning notes are readable by anyone. Supporting history evidence is omitted from current public files, but older Git commits retain previous detailed snapshots and remain accessible because commit history has not been rewritten. Keep resumes, private profile details, customer records, contact information, credentials, identity documents, health records, and banking/tax identifiers out of public files.

Dashboard changes are saved in the current browser and do not sync automatically between devices. **Encrypted backup** creates a passphrase-protected portable copy; store the passphrase separately. **Plain JSON backup** remains available but is unencrypted. **Restore** accepts either format. **Export tasks** creates a separate fresh task snapshot; the desktop watcher publishes allowlisted task fields and milestone summaries without free-text history evidence to the public repositories for the 9 AM review. On Pages, **Load latest tasks** fetches that feed after a fresh sync; confirm before replacing browser-local task changes and back them up first. The published task snapshot is generated from a reconciled current-user export. Statuses still require evidence review before completion claims.

The desktop source and full operating notes are in the [`varunjakkampudi-tech/personal-hq` repository](https://github.com/varunjakkampudi-tech/personal-hq).
